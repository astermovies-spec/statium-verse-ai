# StadiumVerse AI
**One AI Platform. Every Fan. Every Match. Every Second.**

A fully functional AI-powered Smart Stadium and Tournament Operations Platform designed for the FIFA World Cup 2026, utilizing Google Cloud technologies.

## Architecture Highlights
- **Multi-Agent Network**: An advanced routing architecture powered by `Gemini-3.5-Flash` that acts as a collaboration hub for 6 specialized agents (Fan, Organizer, Security, Medical, Volunteer, Vendor). It includes chain-of-thought visualizers on the client.
- **Digital Twin Maps**: A 3D stadium telemetry visualization map built entirely in React/CSS that supports layer toggles (Heatmap, Crowd Density, Emergency Routes) and real-time panning.
- **BigQuery / Recharts Analytics**: 14-day live trend predictions and real-time visualization of crowd flow, energy consumption, revenue, and wait times using Recharts.
- **Role-Based Authentication**: Secure access portal leveraging Firebase Authentication contexts. Supports Google Sign-In and Developer Role overrides (Admin, Security, Medical, Organizer).
- **Responsive & Accessible Design**: Glassmorphism, gold gradients, 100% WCAG-compliant contrasts, and intelligent fallbacks.

## Development Stack
- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4 + Framer Motion
- Google Cloud Gemini SDK (`@google/genai`)
- Recharts
- Firebase
- Lucide Icons

## Setup
1. Clone the repository
2. Run `npm install`
3. Create a `.env.example` file and add `GEMINI_API_KEY`, along with `NEXT_PUBLIC_FIREBASE_*` credentials.
4. Run `npm run dev` to launch the platform locally.
